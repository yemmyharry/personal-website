# Project Instructions & Agent Guidelines

## Critical Workflow Rules
1. **Always do changes in a new branch**: Never commit directly to `main`. Create and checkout a dedicated feature/topic branch (e.g., `feat/...`, `fix/...`) before modifying and committing code.
2. **Commit messages**: Always keep commit messages concise — a single short sentence (e.g. `Update Ipilẹ Labs card and Bitcoin open source journey.`).
3. **Preserve formatting & accuracy**: Keep existing formatting, styling, typography, and personal info accurate to the owner (Omoyemi "yemmyharry" Arigbanla).
